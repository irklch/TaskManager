# AddTaskView Redesign Documentation

## Обзор изменений

Экран создания задач `AddTaskView` был полностью переработан согласно новому дизайну. Новый интерфейс включает улучшенную структуру, новые компоненты и более интуитивную навигацию.

## Новые компоненты

### 1. TaskStep
**Файл:** `TaskManager/TaskScreenView/AddTaskView/TaskStep.swift`

Модель для представления этапов выполнения задачи:
- `id: UUID` - уникальный идентификатор
- `title: String` - название этапа
- `isCompleted: Bool` - статус выполнения
- `isEmpty: Bool` - проверка на пустоту
- `displayTitle: String` - отображаемое название (с плейсхолдером)

### 2. TaskStepView
**Файл:** `TaskManager/TaskScreenView/AddTaskView/TaskStepView.swift`

Компонент для отображения отдельного этапа задачи:
- Кружок для отметки выполнения
- Поле ввода текста этапа
- Кнопка удаления (для дополнительных этапов)
- Автоматическое добавление нового этапа при заполнении

### 3. FolderPickerView
**Файл:** `TaskManager/TaskScreenView/AddTaskView/FolderPickerView.swift`

Компонент для выбора папки проекта:
- Список доступных папок
- Визуальное выделение выбранной папки
- Чекмарк для текущего выбора

### 4. DeadlinePickerView
**Файл:** `TaskManager/TaskScreenView/AddTaskView/DeadlinePickerView.swift`

Компонент для выбора дедлайна:
- Календарный виджет выбора даты
- Опция "Без даты"
- Кнопки подтверждения и отмены

## Обновленный AddTaskViewModel

### Новые свойства:
- `@Published var selectedFolder: TaskFolder?` - выбранная папка
- `@Published var taskSteps: [TaskStep]` - этапы задачи
- `@Published var deadline: Date?` - дедлайн
- `@Published var hasDeadline: Bool` - флаг наличия дедлайна
- `@Published var showingFolderPicker: Bool` - показ селектора папок
- `@Published var showingDatePicker: Bool` - показ селектора дат

### Новые методы:

#### Управление папками:
- `showFolderPicker()` - показать селектор папок
- `hideFolderPicker()` - скрыть селектор папок
- `selectFolder(_:)` - выбрать папку

#### Управление этапами:
- `updateTaskStep(at:with:)` - обновить этап
- `addNewTaskStep()` - добавить новый этап
- `removeTaskStep(at:)` - удалить этап

#### Управление дедлайном:
- `showDatePicker()` - показать селектор дат
- `hideDatePicker()` - скрыть селектор дат
- `setDeadline(_:)` - установить дедлайн
- `removeDeadline()` - убрать дедлайн
- `formattedDeadline()` - форматированная дата

#### Вычисляемые свойства:
- `validTaskSteps: [TaskStep]` - валидные этапы
- `folderName: String` - название папки
- `availableFoldersList: [TaskFolder]` - список доступных папок

## Новый дизайн AddTaskView

### Структура экрана:

1. **Навигационная панель:**
   - Кнопка "Отмена" слева
   - Заголовок "Создание задачи"
   - Счетчик этапов "X/45" справа

2. **Основные поля:**
   - **Название задачи** - большое поле ввода с заголовком
   - **Описание задачи** - многострочное поле с плейсхолдером
   - **Название проекта** - выпадающий список папок с кнопкой "Добавить новую"
   - **Этапы выполнения** - динамический список этапов с кружками
   - **Дедлайн** - выпадающий селектор даты

3. **Нижние кнопки:**
   - **"Добавить файл"** - кнопка для прикрепления файлов
   - **"Сохранить задачу"** - основная кнопка сохранения

### Интерактивные элементы:

- **Автоматическое добавление этапов:** При заполнении последнего этапа автоматически добавляется новый
- **Выбор папки:** Модальное окно с списком доступных папок
- **Выбор дедлайна:** Модальное окно с календарем и опцией "Без даты"
- **Валидация:** Кнопка сохранения активна только при заполненном заголовке

## Интеграция с существующей архитектурой

### Обновления ContentViewViewModel:
- Добавлено свойство `selectedFolder` для синхронизации выбранной папки
- Обновлен `tabItems` для передачи `selectedFolder` в `TaskScreenView`

### Обновления TaskScreenView:
- Добавлен параметр `selectedFolder: Binding<TaskFolder?>`
- Синхронизация выбранной папки между View и ViewModel

### Обновления ContentView:
- Передача `selectedFolder` в `AddTaskView` при создании новой задачи

## Преимущества нового дизайна

1. **Улучшенная структура:** Логичная группировка полей с четкими заголовками
2. **Интуитивная навигация:** Использование стандартных UI паттернов iOS
3. **Динамические этапы:** Автоматическое добавление этапов по мере необходимости
4. **Гибкость:** Возможность работы без дедлайна
5. **Визуальная обратная связь:** Четкие индикаторы состояния и валидации
6. **Консистентность:** Единый стиль с остальным приложением

## Технические особенности

- **MVVM архитектура:** Полное разделение логики и представления
- **Реактивность:** Использование `@Published` свойств и Combine
- **Модальные окна:** Использование `.sheet()` для выпадающих селекторов
- **Фокус управление:** Автоматическая фокусировка на поле заголовка
- **Валидация:** Проверка заполненности обязательных полей
- **Синхронизация:** Автоматическая синхронизация состояния между компонентами

## Заключение

Новый дизайн `AddTaskView` значительно улучшает пользовательский опыт создания задач, предоставляя более структурированный и интуитивный интерфейс. Все изменения полностью интегрированы с существующей MVVM архитектурой проекта.
